# Qubo audio sources

All assets listed below are CC0 1.0. The game selects one distinct audio file for each of its 30 environments. Audio is streamed on demand in this preview build; it is not yet bundled in the Qubo app.

- Stage 3 — Sea: recording by SamsterBirdies, Freesound 578524. https://freesound.org/people/SamsterBirdies/sounds/578524/
- Stage 4 — Desert: “breeze.wav” by keweldog, Freesound 181801. https://freesound.org/people/keweldog/sounds/181801/

- Stage 15 — Solitude: “ambient low hum (aircon)” by TimBahrij, Freesound 234918. https://freesound.org/people/TimBahrij/sounds/234918/

## One-shot game effects

- `spin.ogg`: “Whoosh low” by MeanRaccoon, Freesound 830856, CC0 1.0. https://freesound.org/people/MeanRaccoon/sounds/830856/
- `wood-2.ogg`: wooden door-close foley from Kenney’s RPG Audio pack, CC0 1.0. https://kenney.nl/assets/rpg-audio

If an external audio file is unavailable or the device is offline, Qubo falls back to its built-in quiet scene soundscape.
